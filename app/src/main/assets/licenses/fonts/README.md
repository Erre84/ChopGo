# Tipografía del panel 0.3.7

- Nombre de la app: Michroma Regular, Vernon Adams.
- Texto: Chakra Petch Regular, Cadson Demak.
- Controles, cifras y pads: Chakra Petch SemiBold, Cadson Demak.

Fuentes originales, sin modificar, obtenidas de Google Fonts:
https://github.com/google/fonts/tree/main/ofl/michroma
https://github.com/google/fonts/tree/main/ofl/chakrapetch

Distribuidas con SIL Open Font License 1.1; se conservan ambas licencias junto a este archivo. Los nombres de archivo de recurso Android difieren del nombre de la familia.

La dirección visual está inspirada en la rotulación geométrica de los samplers E-mu. No se utiliza el logotipo ni una tipografía oficial de E-mu. Las fuentes están incluidas en la APK y no requieren una descarga al iniciar.
